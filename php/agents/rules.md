# Regras do projeto

1 - Somente arquivos dentro da pasta PHP
2 - Estou proibido de pegar dados do banco de dados, somente por json do node.
3 - O Foco é criar paginas costomizado com base no root do projeto e usando o fremework boostrap
4 - Todo o codigo php tem que ser tipado ou focando em boas praticas de segurança, Ex: htmlspecialchars($varUser);
5 - sem logica dento das views, nela vai ter somente html ou php para mostrar dados Ex: foreach ou if
6 - Quando enviar o comando, quero que me explique o porque desse codigo está no projeto e o que ele faz.
7 - evite criar um codigo de uma vez, quero funções organizadas para cada parte e função do projeto.
8 - Os sugestções fantasmas vai ter que validar essas regras também para um melhor resultado
9 - O css normal fica no arquivo style.css, o que deixa responsivo(@media) fica no media.css, no arquivo media.css coloque o minimo de codigo possivel apenas para ficar responsivo no celular.
10 - Todas as views, funções do providers e assets, vai passar pelo index.php(font-controller).
